Q:
why we need to do below things?
- 添加 `spring-boot-starter-web` 依賴

**你要做的是「可對外提供下載 API 的 backend」**，而不只是單純在程式內呼叫 library。

`spring-boot-starter-web` 主要提供這些關鍵能力：
1. **Spring MVC / REST**：讓 `@RestController`, `@GetMapping` 這些註解生效。  
2. **內建 Web Server**（Tomcat）：`mvn spring-boot:run` 就能直接開 HTTP 服務。  
3. **HTTP 請求/回應整合**：例如 `HttpServletResponse`、下載檔案 response header（`Content-Disposition`）等。  
4. **Web 相關自動配置**：少寫很多樣板設定。

如果不加 `spring-boot-starter-web`，你還是可以「在本地程式碼中」用 `sprintBootExcelDemo` 產 excel，但**不能直接用 HTTP endpoint 提供下載**（除非你自己手刻 server 與 MVC）。

所以你這個情境（`/api/excel/download`）加它是最合理且最省工的作法。
