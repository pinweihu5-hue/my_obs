# 兒童心理與注意力評估：張哲嘉醫師回診要點簡報

本報告旨在彙整台大醫院兒童心理科張哲嘉醫師針對一名就讀國小一年級（約六歲半）男童之 SNAP-IV 評估量表結果及臨床觀察。內容涵蓋個案在校表現、家庭互動、量表分析以及醫師建議之干預策略。

--------------------------------------------------------------------------------

## 執行摘要

本個案正處於國小一年級適應階段，臨床觀察顯示其具備明顯的過動（Hyperactivity）特質，並伴隨部分亞斯伯格（Asperger）特徵，但以過動表現較為突出。

量表結果顯示個案在「注意力不集中」與「好動／衝動」範疇得分較高，尤其在校端的表現更為顯著。

目前核心挑戰在於個案的心智年齡（或行為表現）較同齡孩子更偏向幼兒，對於抽象的規範與高強度的國際班課程適應較為吃力。

**核心結論：**

- **臨床診斷傾向：** 過動特質強於亞斯伯格特質，**屬於「調皮、不專心、不配合」但仍可被規範制約**。
- **教學適應：** 國際班課程難度偏高，導師管理風格偏向細微管理（Micro-management），與個案活潑天性產生磨擦。
- **建議策略：** 優先採取「遊戲化教學」與「任務導向」的介入模式，暫緩藥物治療，著重於親師溝通及個案動機的引導。

--------------------------------------------------------------------------------

## 一、 SNAP-IV 兒童注意力量表分析

根據家長與學校老師（包含主副班導、外師等五位老師）共同填寫之 SNAP-IV 量表，診斷重點如下：

|   |   |   |
|---|---|---|
|評估項目|臨床觀察與數據|說明|
|**注意力不集中**|二、三分項目達六項以上|醫師指出，各體六項以上即需關注。外師特別反應其英語學習專注度較差。|
|**好動與衝動**|得分較高，表現明顯|包含上課離座、在地板找東西、影響上課秩序及排隊秩序。|
|**對立反抗**|部分呈現|表現為對於成人的指令先給予拒絕（Reject），但在有技巧的引導下可被調整。|
|**臨床意涵**|高於臨界點|老師端的評分普遍高於家長端，顯示個案在團體規範下的壓力較大。|

--------------------------------------------------------------------------------

## 二、 學習環境與在校行為觀察

### 1. 班級環境挑戰

- **課程強度：** 個案就讀私立學校國際班，課程難度高（小一已教導動詞、形容詞與名詞），對於理解力稍弱或專注力不足的個案造成壓力。
- **管理風格：** 導師風格屬於細微管理與正向鼓勵並進，但對調皮男生的容忍度相對較低，導致個案與老師間存在「磨合壓力」。
- **同儕互動：** 個案與特定幾位同學互動時會出現過度興奮或違反秩序的行為，雖具備社交技巧，但容易受衝動特質影響。

### 2. 課堂具體表現

- **分心行為：** 在聽不懂（如外師課）或感到無聊時，會離開座位或在地板找東西。
- **制約潛力：** 各方評語顯示個案是可以被規範與調節的，但需要採取「博感情」或「特定技巧」來引導。

--------------------------------------------------------------------------------

## 三、 家庭互動與管教現狀

### 1. 互動模式

- **溝通斷層：** 醫師觀察到家長傾向使用「大人」的語言與個案溝通（討論規則、任務），而個案則以「小孩」的方式回應（發出噪音、開玩笑、做怪表情），導致雙方未能完全同步。
- **延宕滿足：** 個案在延宕滿足的能力上較弱，具有先天與後天共同影響的特質，需立即獲得回應。

### 2. 管教技巧

- **獎勵機制：** 家長已建立點數或分鐘數制度（例如跳繩賺取影片觀看時間），個案對此有動機且能完成任務。
- **自主意識：** 個案極度自主，傾向事事自己來。若家長具備化解技巧，能在幾秒鐘內調整其行為。

--------------------------------------------------------------------------------

## 四、 醫師專業建議與干預方針

張哲嘉醫師針對個案的後續發展提出以下核心建議：

### 1. 介入模式：遊戲化與低難度化

- **任務導向（Task-oriented）：** 建議將學習與規範轉化為遊戲。例如將「遵守規則」包裝成「飛行員升階任務」，利用其對飛機的愛好來驅動動機。
- **降低難度：** 考量個案目前的心智年齡與能力，學習難度不宜設得太高，應以「玩樂」作為主要學習媒介。

### 2. 心理需求滿足

- **高品質陪伴：** 醫師推測個案某些「不正經」的行為可能是為了引起注意。建議每天安排 10-30 分鐘的「自由玩樂時間」，由個案主導，家長純粹陪玩，不設任何規範。
- **理解語言：** 家長需先進入個案的「語言世界」（玩樂、非正式溝通），建立信任感後再帶入任務要求。

### 3. 親師溝通策略

- **尋找亮點：** 家長應多與老師分享個案在家的成功案例與亮點，引導老師看到個案的優點，而非僅關注其違規行為。
- **特質標籤化轉向：** 讓老師理解個案具有「好動特質」，共同尋找適合的介入力度，而非單純要求個案符合所有常規框架。

### 4. 醫療計畫

- **藥物治療：** 目前家長與醫師達成共識，暫不使用藥物，先透過行為引導與環境調整觀察成效。
- **後續追蹤：** 預計於三、四月間回診，重點觀察個案在下學期的適應狀況，並鼓勵個案參與診間討論，表達自己的想法。

## 五、 重要語錄

「他（個案）可能放進我們所謂學校或家裡的框架當中，就會有一些摩擦……他在選兒童其實本身就有 ADHD（過動）那個特質……我覺得專注度跟沒耐心的感覺多一些。」 —— **張哲嘉醫師**

「我們父母的角色是理解小孩之後，去尋找適合他的環境或跟學校做溝通……他現在其實沒想要討論這麼多太複雜的東西，他一直想用小朋友的方式跟我們講話。」 —— **張哲嘉醫師**

「（量表分數）二、三分就算了，就算是以比較稍微多一些……老師的（評分）都很多啦。」 —— **張哲嘉醫師**
