how visitor pattern logic flow:

begin 
```java
class Interpreter implements Expr.Visitor<Object> {  
  
    void interpret(Expr expression) {  
        try {  
            Object value = evaluate(expression);   // call this line
            System.out.println(stringify(value));  
        } catch (RuntimeError error) {  
            Lox.runtimeError(error);  
        }  
    }
```


which call this method in the same class
```java

private Object evaluate(Expr expr) {  
    return expr.accept(this);  
}

```



which call this Expr.Binary `accept` due to 多型 (since `Interpreter` impl `Expr.Visitor<Object>`)
