分析完成。結論：__`/export` endpoint 既不是 Streaming HTTP API，也沒有使用 POI Streaming。__

__問題一 (HTTP 層)__：Controller 回傳 `ResponseEntity<byte[]>`，並用 `ByteArrayOutputStream.toByteArray()` 將整個 Excel 先完整寫入記憶體再一次性回傳。應改用 `StreamingResponseBody` 才是真正的 HTTP Streaming。

__問題二 (POI 層)__：ExcelService 使用 `XSSFWorkbook`（全量記憶體模式），會把所有 row/cell 全存在 JVM heap。應改用 `SXSSFWorkbook`（滑動視窗模式），只在記憶體保留固定數量的 row，超出的會 flush 至磁碟暫存，大幅降低記憶體消耗。

資料量小時影響不明顯，但大資料量（10萬筆以上）時有 OutOfMemoryError 的風險。
