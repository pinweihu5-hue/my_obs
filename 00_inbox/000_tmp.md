📋 NATS JetStream 訊息可靠性驗證 Demo - 完成摘要
🗂️ 專案結構
NAT_Jetstream_Demo/
├── docker-compose.yml      # NATS + NATS Monitor
├── nats-server.conf        # NATS 設定
├── pom.xml                 # Spring Boot + jnats
└── src/main/java/com/ben/
    ├── config/NatsConfig.java      # JetStream 初始化
    ├── model/NotificationMessage  # 完整訊息結構
    ├── service/ChaosService       # 控制失敗模式
    ├── producer/NotificationProducer
    ├── consumer/MainConsumer      # 主消費者（可失敗）
    ├── consumer/DlqConsumer       # DLQ 監控
    └── controller/
        ├── NotificationController  # 發送訊息 API
        └── ChaosController        # 控制 API
🚀 啟動方式
cd NAT_Jetstream_Demo
# 1. 啟動 NATS
docker-compose up -d
# 2. 啟動 Spring Boot
./mvnw spring-boot:run
🧪 測試流程
1. 發送正常訊息
curl -X POST "http://localhost:8080/api/notifications/send/simple?title=Test&name=Ben&content=Hello"
2. 啟用失敗模式
curl -X POST "http://localhost:8080/api/chaos/enable?keyword=FAIL"
3. 發送會失敗的訊息
curl -X POST "http://localhost:8080/api/notifications/send/simple?title=Test&name=Ben&content=FAIL"
4. 查看狀態
curl http://localhost:8080/api/chaos/status
5. 查看 DLQ 訊息
curl http://localhost:8080/api/chaos/dlq
6. 查看 NATS 監控 UI
http://localhost:9222/monitoring
